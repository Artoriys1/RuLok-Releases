# Pax Autocratica

Тестовый русский перевод Artoriys1 для Steam Windows, сборка 26736596.

1. Обновите список «Все моды и русификаторы» в RuLok.
2. Откройте Pax Autocratica и выберите «Русификатор». Укажите папку игры и нажмите «Установить».
3. Для обновления, проверки и удаления используйте кнопки выбранного перевода в RuLok.
