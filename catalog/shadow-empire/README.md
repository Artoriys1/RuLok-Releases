# Русификатор Shadow Empire

Полный перевод. Перевёл интерфейс, подсказки, военные отчёты и тексты сценариев. Перевёл также тексты дополнений Oceania и Republica.

Версия 0.2.64 подходит для Shadow Empire 1.32.4 в Steam, GOG и Matrix Games. Для Matrix Games требуется RuLok 0.6.36 или новее.

Нажмите «Подключить» у Shadow Empire в каталоге RuLok и укажите папку игры. Затем выберите русификатор в библиотеке и нажмите «Установить». Если перевод уже установлен, нажмите «Обновить» в его карточке.
