# RebornMod для «Шторм: Солдаты неба»

Доработал управление, меню и подсказки в обучении. Адаптировал игру к широким экранам и современным версиям Windows. Сохранил исходные миссии и ручное управление командами.

Поддерживается русскоязычный релиз Steam, версия 1.10.27 (сборка 347930).

[RebornMod 1.3.33](https://github.com/Artoriys1/RuLok-Releases/releases/tag/echelon-reborn-1-3-33-20261119) устанавливается через [платформу RuLok](../../README.md). Подключите папку игры в RuLok, выберите RebornMod и нажмите «Установить».
