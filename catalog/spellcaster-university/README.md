# Русификатор Spellcaster University

Частичный перевод в версии 0.1.3. Перевёл интерфейс, карточки, подсказки, события и реплики.

Нажмите «Подключить» у Spellcaster University в каталоге RuLok и укажите папку игры. Установите русификатор из библиотеки и выберите «Русский» в настройках игры.

Поддерживаются Steam и другие совместимые копии Windows. Базовая сборка 26035424. При допустимых расхождениях RuLok предлагает установить проверенные части.
